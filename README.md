# 🔴🍎 Red Team na macOS

> **Kompendium wiedzy ofensywnej i detekcyjnej** — stan na sierpień 2026

## 📖 Czytaj online: [zi3lak.github.io/redteam-na-macos](https://zi3lak.github.io/redteam-na-macos/)

Kompletna ścieżka operacji red team w środowiskach **macOS** — od dostępu początkowego po pełną kontrolę nad stacją Apple. Wszystko zmapowane na **MITRE ATT&CK** 🎯 i opatrzone kontrapunktem detekcyjnym 🛡️

### Co znajdziesz w środku? 🔥

- 🔓 **Obejścia zabezpieczeń Apple** — Gatekeeper, TCC, SIP, notaryzacja
- 🥷 **Persistence na macOS** — LaunchAgents/Daemons, profilowanie, mechanizmy logowania
- 🎯 **Pozyskiwanie poświadczeń** — keychain, TCC.db, phishing okien systemowych
- 🌐 **Infrastruktura C2** — implanty pod Apple Silicon, kamuflaż ruchu
- 🔍 **Telemetria detekcyjna** — Endpoint Security Framework, Unified Log
- 📈 **Trendy zagrożeń** — stealerty, malware podszywający się pod legalne aplikacje

### ⚠️ Zastrzeżenie

Materiał **wyłącznie** do celów edukacyjnych, autoryzowanych testów bezpieczeństwa i budowania detekcji. Użycie opisanych technik bez pisemnej zgody właściciela systemu jest przestępstwem (art. 267–269 KK).
